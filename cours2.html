    1.4 Perceptron multi-couches (multilayer perceptron)

    C’est mieux, mais avec une seule application de la fonction d’activation, nous n’ajoutons qu’une seule inflexion. Pour en ajouter plusieurs, il faut : 1 - introduire plusieurs résultats intermédiaires cachés 1 - les combiner pour avoir un seul résultat

    Si nous voulons 3 inflexions, il nous faut 3 résultats intermédiaires. Nommons les h1, h2, h3. Pour chaque résultat, il nous faut des paramètres correspondants. Pour chaque résultat intermédiaire hi, nous aurons 2 poids wi1, wi2 (un par dimension en entrée), et un biais bi.

    TODO colors !!! Represent as a vector ! h1 = sigma(sum(w1j.xj) + b1) h2 = sigma(sum(w2j.xj) + b2) h3 = sigma(sum(w3j.xj) + b3)

    Ensuite, nous combinons ces résultat comme si il représentaient un vecteur d’entrée à 3 dimensions. Il nous faut un autre vecteur de poids et un autre biais que nous appelerons v et c.

    Notre modèle final devient : y = sigma(v1.h1 + v2.h2 + v3.h3 + c)

    Il possède 4 neurons: 3 neurons dans la couche cachée, un neuron dans la couche de sortie. Ces paramètres sont (i=0 to 3, j=0 to 2) wij, bi, vi, c TODO représenter sous forme vectorielle avec tous les paramètres TODO montrer le graphe de calcul avec les connections

    1.5.1 Multiplication de matrices

    En mathématiques, la multiplication de deux matrices A et B est définie comme suit : Soit une matrice A de dimensions mn (m lignes, n colonnes) Soit une matrice B de dimensions no La multiplication A x B produit une matrice C de dimensions m*o. Chaque cellule Cij est calculée de la manière suivante : Cij = somme Aik x Bkj

    Pour pouvoir multipler deux matrices, leurs dimensions doivent être compatibles. nombre de colonnes de la matrice A = nombre de lignes de la matrice B

    1.5.2 Addition

    On peut ajouter 2 matrices A et B si elles ont les mêmes dimensions. Cela consiste à ajouter les cellules de mêmes coordonnées.

    Cij = Aij + Bij

    1.6 Perceptron avec matrices

    Grâce à nos nouveaux outils, nous pouvons réécrire notre modèle de perceptron avec la notation matricielle : h = sigma(W.x + b) y = sigma(V.h + c)

    Cet écriture est très pratique, et elle nous rappelle la formule utilisée pour une transformation linéaire. Par ailleurs, les bibliothèques Python modernes sont optimisées pour le calcul matriciel. Elles peuvent effectuer de nombreux calculs en parallèle grâce au GPU.
